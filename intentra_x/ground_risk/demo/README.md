# Ground-risk demonstration assets

This directory stores representative Hohhot maps and animations together with
the scripts that reproduce them from the integrated INTENTRA-X modules.

- `legacy_outputs/` retains the user's existing PNG/TIF/GIF demonstration files.
- `legacy_scripts/` retains the original Hohhot rendering scripts for traceability.
- `generate_hohhot_gif.py` is the new generator that calls the integrated engine.
